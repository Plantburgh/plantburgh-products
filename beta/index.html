Android apps

These install directly (they're not on the Play Store yet — that's deliberate during beta). Android will warn you about installing outside the store; that warning is about unknown files in general, not these in particular.

  1. On your Android phone, tap an app below and download the .apk file.
  2. Open the downloaded file. The first time, Android asks you to allow your browser to install apps: tap Settings → Allow from this source, then go back.
  3. Tap Install. If Play Protect asks, choose Install anyway — the warning appears for every app that doesn't come from the store.
  4. Updates: install the newer file over the old one the same way — your data stays.
