How to install

  1. On your Android phone, tap Download above. You get an .apk file.
  2. Open the file. The first time, Android asks you to let your browser install apps: tap Settings, turn on Allow from this source, then go back.
  3. Tap Install. If Play Protect warns you, tap More details → Install anyway. It warns about every app that doesn't come from the Play Store, not about this one in particular.
  4. Open the app. It asks for permissions only when a feature needs them (list above).

Updates

  • Install the newer file over the old one, the same way. Your data stays.
  • Or let Obtainium (free, open source) do it: tap ➕ and paste https://github.com/Plantburgh/plantburgh-products. It updates every tester app in place.
  • Stay with one source. If you later get the same app from Google Play, the two copies may not be able to update each other. Make a backup first if the app has one, then uninstall the file version before installing from Play.

Your data

Everything stays on your phone. The app keeps a daily backup on the phone (the last 7), and Settings → Backup exports a file you can keep anywhere and restore later.

Coming from Loop Habit Tracker? Import its backup ZIP in Settings.

Something wrong?

Use Send beta feedback inside the app (in Settings). It shows you exactly what it will send, copies it, and you paste it to Andre in a text or email. Nothing is sent on its own.
